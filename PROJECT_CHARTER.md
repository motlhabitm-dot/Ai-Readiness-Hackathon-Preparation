# Project Charter

## 1. Project Scope
Build a secure, AI-assisted project management dashboard over 5 days by integrating GitHub, Microsoft Copilot Studio, Power Platform, and Responsible AI principles to streamline workflows and enforce team governance.

## 2. Team & Ownership
* **Team Lead / Demo Owner:** Thogonolofatso Motlhabi - Manages the final presentation, live walkthrough, and overall coordination.
* **Build Owner:** Andiswa Dlamini and Mpilo  Zikhali - Oversees Power Platform and Copilot Studio configuration.
* **Review Owner:** Gugulethu Nzama — Enforces GitHub branch protections, PR reviews, and secret scanning checks.
* **Data & Governance Owner:** Ayanda Mnyango — Manages data sources, schemas, and ensures alignment with Responsible AI guidelines.

## 3. Success Measures (KPIs)
* 100% adherence to branch protection rules (zero direct pushes to `main`).
* Zero secret/credential exposures flagged by security scanners.
* Working automated end-to-end integration between GitHub and Power Platform / Copilot Studio.
* Documented Responsible AI framework audit before deployment.

## 4. Weekly Milestones
* **Day 1:** GitHub repository setup, security controls, project board, and charter delivery.
* **Day 2:** Data models and initial Power Platform / Copilot Studio setup.
* **Day 3:** Workflow automation, triggers, and integration testing.
* **Day 4:** Responsible AI audit, UX polish, and end-to-end dry run.
* **Day 5:** Final presentation and live working demo.
