# Ai-Readiness-Hackathon-Preparation

### Corporate Training AI Project Management Dashboard

A 5-day hackathon initiative to build a secure, AI-assisted project management solution integrating GitHub, Microsoft Copilot Studio, and Power Platform, aligned with Responsible AI governance standards.


## Repository Documentation

* [Business Challenge Statement](BUSINESS_CHALLENGE.md) - Problem statement, affected stakeholders, and business impact.
* [Project Charter](PROJECT_CHARTER.md) - Scope, team member responsibilities, KPIs, and weekly milestone targets.
* [Contribution Guidelines](CONTRIBUTING.md) - Branch naming standards (`feature/<initials>-<topic>`), PR review requirements, and credential safety rules.


## Solution Overview & Tech Stack

* **Source Control & Governance:** GitHub (Branch protection, PR workflows, Secret scanning)
* **AI & Assistant Layer:** Microsoft Copilot Studio
* **Workflow Automation:** Microsoft Power Platform
* **Governance Framework:** Responsible AI principles
